## 📝 Notes

- **Saturated/dynamic colors** (e.g., `bg-indigo-500`, `text-primary-600`, `bg-gradient-to-r`) were intentionally left unchanged — they still work in dark mode since they provide their own visual contrast.
- **Function-returned class strings** (e.g., `statusBadgeClass()`, `getStatusClass()` returning `'bg-emerald-50 text-emerald-700'`) were not modified to avoid breaking dynamic behavior. These may need manual `dark:` additions at the function level.
- **Glass effects** in `AuthLayout.vue` use `dark:bg-slate-800/80` to preserve the translucent frosted-glass appearance in dark mode.
- **Shared components** (e.g., `InputField.vue`, `PasswordInput.vue`) already have dark mode and are reused across all auth/company/tutor pages.
